# Auckland Wedding Dance

Static website for Auckland Wedding Dance: private wedding dance lessons in South Auckland.

Plain HTML/CSS/JS, no build step. Open `index.html` or deploy the folder to any static host (GitHub Pages, Netlify, Vercel).

- `index.html`, `about.html`, `lessons.html`, `studio.html`, `gallery.html`, `contact.html`
- `styles.css`: shared styles and responsive breakpoints
- `main.js`: mobile menu, reviews carousel, FAQ, enquiry form
